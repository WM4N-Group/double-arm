# X7 双臂搬箱：严格碰撞修正与审计

旧视频 seed 6000 确认有穿模。旧版只给台面启用了碰撞，视觉桌腿和托梁为空。用旧轨迹、回合内实际底盘位姿与原始 1,674,572 三角面 CAD 比对，A 台内侧腿在 **7.23–9.37 s**、B 台内侧腿在 **11.40–13.53 s** 分别有 **65 个控制帧**包含落在腿内的 CAD 顶点。顶点距最近盒面最深约 36 mm（不是整体分离深度）。旧数据保留，追加 `COLLISION_INVALIDATED.json`，整批 8 条不能作为碰撞合格训练数据。

## 改动与结果

- 桌面、腿、梁与横撑的六个结构件使用相同的视觉和碰撞盒；桌腿移至底盘侧向路径之外。使用原始和显示版底盘 CAD 的所有三角面计算分高度的保守碰撞包络，外扩 2 mm。要求原始 CAD 基座 STL SHA-256 完全匹配，不能用空网格替代。
- 用有符号距离和实际接触计数检查全部机器人链节到两张桌子，不按法向力筛掉接触。每回合初始 96 子步＋控制 5,280 子步共 **5,376 次检查**，规定两台均无接触且最小距离 ≥5 mm。前两版全碰撞几何因台面／底盘包络重叠被拒绝；前移台面及调整拾取位置后才通过，未关闭碰撞以放行。
- 完整移动源回合 2.65 m，最小距离 **13.51 mm**，机器人–站台零接触、零负距离。独立的全 X 区间底盘包络扫掠加计横向／偏航范围和额外 2 mm 水平余量，A/B 台的保守下界均 **11.26 mm**。后者仅覆盖指定底盘姿态范围，不是所有姿态下的连续全身认证。
- 三条新的合格源示范生成 **8/8 台距微扰回合**（6/2）；这 8 条在同一门槛下均通过，最小距离约 13.51 mm。旧数据不能通过新版模型与碰撞合同检查。未启动学习训练。
- 修正后的退化对照：锁底座未到 B，A-only 未完成；B-only 最终到 B 台，但曾下坠约 23 cm、出现非指尖接触，**未完成双侧悬空搬运**。不能把它说成“单臂绝不可能放到 B 台”。
