# 项目存储与迁移约定

| 位置 | 保留内容 |
|---|---|
| Git 仓库 | 主流程源码、少量文本配置、依赖版本／上游提交、测试、实验记录和复现入口。X7 走 `codex/x7`，R1/MoMaGen 主线走各自分支。 |
| 本机 | 轻量 Git 检出、选定的报告和文件清单、极少量必要的视频，以及既有参考 PDF。不下载完整数据集、仿真器、模型权重或环境，不自动删除已有文件。 |
| 远端持久盘 `/mnt/yuanyue/double-arm` | `src/` 上游、`envs/` 环境、`data/` 资产／数据、`runs/` 结果／权重／视频、`cache/` 缓存、`logs/` 日志。先确认挂载与用户配额，而不是只看共享池剩余。 |

原始 X7 交付包通过带 SHA-256 的归档存储，`x/` 不作为 Git 源目录。新增实验证据默认保存 JSON/小型清单，视频与数据以相对项目根路径及哈希引用。发布到 Git 前只 `git add` 明确列出的轻量路径；不把整个 `x/` 或远端目录递归加入。

## 换服务器时

1. 确认接入的是目标机器，分别核验存储后端和可用 GPU；不要沿用旧的 UUID 分配或 `latest-*` 活跃任务指针。保留旧服务器上的历史进程/任务记录。
2. 从 Git 固定提交或 bundle 恢复分支；从选择性归档恢复有必要的资产、已最终定稿的数据与检查点。用源端清单逐文件校验 SHA-256，并注明未迁移项。传输走远端流，不在本机落整包。
3. 重建隔离环境，而不是原样覆盖目标或复制环境目录到 Git。X7 CPU 版本见 `config/x7-cpu-requirements.txt`，外部 FFmpeg 供视频验证。MoMaGen、OmniGibson、Isaac Sim 与训练依赖按 `config/upstream.env` 和既有主线约束单独处置，不能推断 A800 可用就代表渲染成功。
4. 凭据、密钥和许可确认不写入迁移包；仅用户明确确认许可后才设置相应标志。连接参数可放 Git 忽略的 `config/*.local.env`，不填密码。
5. 单独报告源码恢复、依赖安装、完整仿真通过、数据生成和训练。大批次分片按阶段验收；未经校验的传输或中断中的 shard 不计入完成数。
