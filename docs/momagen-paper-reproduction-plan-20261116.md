# MoMaGen论文复现：范围、差异与后续验收

## 目标与边界

用户确认按作者论文复现项目推进。先完成 **Tidy Table / D0 / 原版π₀** 子实验，再扩展任务与随机化等级；单个视频通过不是整篇论文结果复现。WB-VIMA与π₀是论文比较的独立策略，不将其误写为串联的“WB-VIMA导航＋π₀操作”。

本文件是后续对齐计划，不改动当前训练的数据、标签、归一化、优化器或验收条件。当前16条数据、batch1、旧权重热启动的额外90k训练仍是诊断实验，不称为论文同规模训练。

## 论文依据与当前差异

核对版本：arXiv:2510.18316v2，§5.4、Appendix C.1/C.3/C.4。

| 项目 | 论文设定摘要 | 当前项目与待办 |
|---|---|---|
| 数据规模 | 1000条演示，按90%/10%划分 | 当前16条训练＋1整回合留出；需要扩充、固定去重与划分，不能靠重复训练代替多样性 |
| 策略训练 | 原版π₀、LoRA rank32、50k更新、batch64 | 架构部分匹配；当前batch1，额外90k是独立诊断，不是论文等价训练 |
| 图像与动作序列 | 三路RGB缩放224，预测50步 | 该部分已接通；控制命令编码、执行chunk等细节仍需核对作者实现 |
| 标准化 | 动作与本体采用1%–99%分位 | 当前原生主线用mean/std；V2虽采用分位，但更换了底盘标签，不能当作已对齐的论文方案 |
| 数据清洗 | 比较i与i+5端点，逐维差小于1e-3则删除闭区间[i,i+5] | 尚未完整实现；需明确关节字段与边界处理，另建数据版本，不覆盖在训数据 |
| 评测 | 20个未见回合的成功率 | 当前只有单整回合留出和诊断，不能以一个成功视频替代 |
| 算力 | π₀实验使用4张H200 | 当前仅授权GPU1；有效batch64的单卡梯度累积 / 显存方案需先验证，硬件和实现差异如实记录 |

50k×64对应约320万次样本曝光；当前旧30k＋计划额外90k、batch1对应约12万次，**不是因为更新次数更多就等价于论文训练量**。曝光量相同也不能代替数据多样性、优化器更新方式与评测协议一致。

## 推进顺序

1. 完成当前coverage v3诊断及其分阶段闭环，保留失败和成功事实。该结果帮助排查学习 / 控制链路，不升级命名为论文复现成功。
2. 核对公开的作者训练 / 评测实现，重点确认底盘动作表示、静止段清洗字段、执行频率 / chunk和抓取模式。论文未写明的设置标为待确认，不能自行补齐后称其为原设定。
3. 建立独立的论文对齐数据版本：作者原生生成、成功轨迹去重、清洗、整回合固定划分；扩充至该子实验目标规模。所有生成与存储都在服务器。
4. 单卡先做有效batch64的可行性和梯度累积数值检查。只有验证通过才另开正式复现训练；不能把batch1结果改名为batch64。
5. 固定20个未见回合及随机种子，报告成功数 / 总数、失败环节和视频；辅助附着条件、纯物理条件分别报告。作者生成时使用assisted不等于已确认论文评测也使用assisted。
6. 子实验通过后，再扩展到真正双臂协作任务；当前抓杯到水槽不宣称已复现双臂协调、全部随机化等级或sim-to-real结果。

## 验收与报告

- 区分：依赖安装、仿真启动、作者数据生成、监督训练、来源条件策略、未见回合策略、纯物理扩展。
- 论文同设定的评测与额外纯物理检查分栏；不把辅助附着成功计为物理接触抓取，不把源动作回放计为π₀成功。
- 每个数据 / 模型版本记录上游revision、数据指纹、清洗参数、拆分、归一化、有效batch / microbatch / 累积步数、优化器更新数、样本曝光、动作表示和抓取条件。
- 仍只用GPU1；不追加GPU0、不代用户接受新条款。当前在训配置保持不变。
