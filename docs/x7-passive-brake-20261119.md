# X7：两路制动测量失效时，不依赖编码器的制动约束

2026-11-19 在新机 46152 的 CPU 仿真中测试。维持冻结 v2、同一几何／2.5 倍末段时序、前向监测、同一外力注入和 5 mm 独立门槛。在原六个制动评估布局上配对。除无扰动对照外，实时主制动位置冻结、其速度显示为零，独立备用读数丢失；前向量程仍正常，不使用制动编码器决定制动接合或额定力。外部推力依旧 620 N、0.8 s，驱动按独立时钟受限，接合不会取消外力。

模型隔离主驱动的停车力，以 Bullet 的**限力零相对运动约束**模拟关节处的摩擦制动。输入只有现有停车锁存和接合时间，物理求解器自行计算本子步反力；上一子步反力只归档，不参与控制。这不是实物被动制动器、断电机械接合或认证架构；同一个仿真关节承载两类作用，对真实轮地摩擦、制动热衰减、力矩或电源独立性没有结论。只检查现有停车信号到达后的效果，不等价于仿真已验证上游指令、通信或前向测距全部失效时也能停车。

预定义组：无扰动，测量失效且无该制动，强制动即时／延迟 100 ms／延迟 250 ms，弱制动即时。强 XY 单轴 900 N、弱 XY 单轴 160 N；转角上限分别 320／100 N·m，为仿真模型输入而非真机选型结论。正对照为完整搬运，故障中止即使无接触也不计任务完成。

首批零力设置存在反力读数保留为上一条电机指令的歧义，不能靠这一路读数复核隔离。独立单关节试验复现：零／微正设置下位置轨迹近似相同，前者读数仍 −315 N，后者读数更新为 −0.0001 N。复跑在本应隔离的轴用 **0.0001 N（或 N·m）** 微小正上限刷新读数，独立审计每个子步反力不超过当时的上限；不能把无制动对照叫作数学严格零力。初批文件完整保留，汇报采用可审计的复跑。
