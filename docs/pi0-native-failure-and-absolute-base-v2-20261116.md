## 2. 诊断证据与边界

- 在实际训练检查点上，对训练 / 留出各3个真实观测做离线动作误差诊断；教师动作只作数值对照，不发送给模型、不调用仿真控制。原物理闭环末期共享推理服务的这6次请求也消耗了随机数，因此不要将后续对照误称为逐噪声完全配对实验。
- 初始观测附近的底盘前10步归一化RMSE约0.90；原生三维聚合RMSE混合了XY的米和yaw的弧度，不能全部解释为毫米。底盘原生position控制的前三维实际上是每步局部位移 / 转角，误差可能在闭环累积，但**这只是待验证的失败机制，不是唯一已证实根因**。
- 原演示前100步本身已有底盘移动，原生命令不是全0。因此不能把策略前100步0.834m位移全部称为“本该静止时的漂移”。
- 已只用训练集的3个观测比较10/50步去噪、固定高斯 / 零潜变量：聚合归一化MSE约0.0281、0.0287、0.0320、0.0323，没有证据支持换成50步或零噪声能解决问题；后续保持默认10步高斯采样。
- 留出样本诊断不用于选择采样设置。物理抓取失败、16条试跑规模和作者辅助抓取的数据来源都仍是独立限制。

## 3. 两条有界后续工作

### A. 作者配置辅助条件诊断

保持同一30k检查点、三图 / 原21维本体 / 指令、50步预测 / 执行10步、默认10步高斯采样，只恢复作者配置的抓取模式。用途是区分作者辅助条件与纯物理条件的差距，不替代物理验收。

- 单GPU1、最长1.5小时，结果保留 `author_config_task_success`，物理 `task_success` 不会因此变true。
- 视频明确烧入 `PI0 ASSISTED DIAGNOSTIC - NOT PHYSICAL SUCCESS`；允许记录作者辅助动作中的位姿写入，但绝不把这些计数隐去或用于物理通过。
- 诊断结束并释放GPU后，下一轮训练才会启动；不同时运行JAX训练和仿真。

### B. v2：底盘绝对目标 + 分位归一化的工程候选

保留原始π₀模型、预训练基座、rank32、三图、原21维本体、指令和原有16条作者数据，不使用物体坐标、阶段、时间或未来观测作为输入。

1. 只把动作前三维从原生局部单步位移 / 转角，改成**当前机器人根位姿变换后的世界XY / 连续yaw目标**；手臂 / 躯干 / 夹爪其余18维保持原始命令。
2. 使用当前机器人根姿态的XY旋转子矩阵转换平移，不假设roll / pitch精确为0；yaw标签沿各回合连续展开。全部27,657训练帧与1,624留出帧往返恢复原生21维命令，最大误差小于2.5e-7。
3. 推理模型仍只得到三图、21维本体和指令。当前机器人里程计**仅用于低层电机目标转换**，不作为额外VLA输入；不是物体位姿输入或导航规划器。
4. 每一步将绝对底盘目标转回原生局部命令，按训练集原生步长范围限幅，仍经原控制器和物理步进执行；不调用物体 / 机器人位姿setter，不强制抓取 / 不设定路径点。
5. 启用1%/99%分位归一化，向MoMaGen论文Appendix C.3的π₀归一化设置对齐。**世界底盘目标是本项目明确的标签适配实验，不声称复现了作者未公开的全部标签处理。** 未实现论文全部清洗细节，仍不是1000条数据、batch64的论文结果复现。
6. RGB与本体数据直接复用已验证的LeRobot v1文件；新标签只写服务器sidecar，训练时用数据集index查监督标签，随后index被移除，不进入模型。推理没有标签 / index，不会打开sidecar。标签与源provenance均校验SHA256，动作窗口不跨回合。
7. 另开模型配置 / 检查点 / 归一化命名空间 `pi0_r1_tidy_table_absolute_base_lora32`，从官方预训练基座重新微调，不覆盖第一轮30k模型或失败记录。新标签已通过真实官方DataLoader的128帧CPU预检；正式训练前还会重算全部统计并做20步梯度联调。

这是同时改变标签和归一化的工程候选，不是单因素因果消融。是否改善必须看后续物理闭环，不能从数学往返或CPU预检直接推断成功。
