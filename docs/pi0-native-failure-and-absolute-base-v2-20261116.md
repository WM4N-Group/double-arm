## 2. 诊断证据与边界

- 在实际训练检查点上，对训练 / 留出各3个真实观测做离线动作误差诊断；教师动作只作数值对照，不发送给模型、不调用仿真控制。原物理闭环末期共享推理服务的这6次请求也消耗了随机数，因此不要将后续对照误称为逐噪声完全配对实验。
- 初始观测附近的底盘前10步归一化RMSE约0.90；原生三维聚合RMSE混合了XY的米和yaw的弧度，不能全部解释为毫米。底盘原生position控制的前三维实际上是每步局部位移 / 转角，误差可能在闭环累积，但**这只是待验证的失败机制，不是唯一已证实根因**。
