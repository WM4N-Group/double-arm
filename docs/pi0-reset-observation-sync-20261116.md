## 实验1：单次状态加载，分阶段真实RGB快照

同一模拟器进程仅加载一次初态，启动physical模式，依次在累计 **0、1、2、5、20次** `og.sim.step()` 后各render3次并读取真实相机。

- 不调用π₀，不读取教师动作，不执行`env.step(action)`，没有导航 / 抓取规则控制。
- 不复制作者reset_to中的物体移动workaround，不调用任务物体位姿setter；物理步骤中持续审计零辅助附着和零显式任务物体位姿写入。
- 每个快照只保存头 / 左腕 / 右腕RGB与21维本体供离线审计；机器人根位姿另作审计字段，不送入VLA。
- cumulative count是总物理同步步数，不是把0+1+2+5+20逐个叠加。对象位置可能因真实物理自然变化，不能将“无setter”与“场景完全静止”混为一谈。
